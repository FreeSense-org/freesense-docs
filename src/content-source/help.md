This address is retained for older WebUI help links and bookmarks. It does not redirect
automatically. Choose the documentation that matches the firewall you are operating. The version
is shown on the dashboard and on **System → Update**.

- [Stable 1.1: supported production documentation](/) for FreeSense 1.1.0 and later 1.1.x releases
- [Development 1.2: experimental and unsupported documentation](/1.2/)
- [FreeSense 1.0 (frozen): documentation for 1.0.x, no longer maintained](/1.0/)

FreeSense 1.1 replaced 1.0.x as the supported line. To move a 1.0.x firewall, read
[Upgrading from 1.0](/guides/upgrading-from-1.0/). Upgrades are one-way, and moving to Development
is one-way as well. Do not use Development documentation for a production firewall.
