## Navigate the platform

FreeSense is not just a renamed firewall image. The current line introduces a smaller, explicit
package contract; Bootstrap 5 package interfaces; split System and optional-package builds; atomic
Suricata configuration; and CI checks that connect package metadata to the actual build list.

<div class="docs-feature-grid">
  <div><b>Base OS</b><span>Firewalling, routing, interfaces, integrated services, built-in VPN, and the WebUI reference.</span><a href="/base-os/system-administration/">Explore Base OS →</a></div>
  <div><b>Optional Packages</b><span>Packages grouped by job, with installation, lifecycle, operating notes, and package-specific profiles.</span><a href="/packages/catalog/">Explore packages →</a></div>
  <div><b>Operate with confidence</b><span>Updates, observability, diagnostics, recovery, and release provenance for the installed system.</span><a href="/operations/monitoring-and-logs/">Operate FreeSense →</a></div>
