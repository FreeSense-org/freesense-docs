Development 1.2 receives no support and is not for production. Moving a system from Stable to
Development is one-way: the updater never offers a way back. See
[Updates and release channels](/guides/updates-and-channels/).
</Aside>

## One edition, fully open

FreeSense has a single edition. Every feature described here is in the same free build, and the
base system, optional packages, and build pipeline are public and Apache-2.0 licensed. FreeSense
sends no telemetry and needs no account. Read the [introduction](/introduction/) for the project's
origins and how releases are built and signed.
