The release lock is `config/releases/1.1.12.json` in the `freesense-os-base` repository. It moves the
FreeBSD platform to a newer snapshot and all three FreeSense repositories to their `RELENG_1_1`
heads. Every published 1.1 release is tagged `v1.1.N` in those repositories.

1.1.12 supersedes 1.1.11. **1.1.11 is not withdrawn**, and there is nothing to do before updating. A
version number is never reused. Older release notes are on
[Previous 1.1 releases](/releases/previous-1.1/).

## What changed

### WebUI

- **A two-row top bar.** The menu has its own row under the header, within the page width, so a long
  menu fits at every width. The line under the menu spans the full window width.
- **Page width is 1200 px by default.** The new default, **Classic**, keeps pages compact. **Wide** and
  **Full window width** are options in **System → General Setup**, and so is an **icons-only** menu for
  a narrower bar. The top bar shows icons and text by default and fits every page width
  automatically. The first menu entry is now called **Dashboard** instead of Home.
- **A notifications panel under the bell.** The bell opens a panel with the current notices, also when
  there are none, instead of only acting when something is waiting. Dialogs open with a short zoom.
- **One current item per menu.** Grouped menus no longer show a second title and mark a single item as
  current.

### Security

- **WebUI hardening from the security audit.** Deleting a traffic shaper queue, a gateway or a package
  needs a POST request. Serialized data, redirects and shell arguments are handled safely.
- **Platform.** The FreeBSD snapshot is newer. PHP is unchanged at 8.5.12. Which FreeBSD security
  advisories apply to 1.1.12 is listed on the
  [security site](https://security.freesense.org/all/?version=1.1). See
  [Security advisories](/guides/security/).

### Optional packages

Update them in **System → Package Manager → Installed Packages**.

- **Telegraf starts again.** The configuration FreeSense generated used two options that the
  installed Telegraf no longer accepts (`fielddrop` and `ssl_ca`), so the service never started. It
  now writes `fieldexclude` and `tls_ca`.
- **ThreatShield keeps local DNS names working.** In the primary DNS mode, names from the DNS
  Resolver host and domain overrides, DHCP domains and aliases in domains other than the system domain
  stopped resolving. ThreatShield now hands every local domain to Unbound.
- **ThreatShield loads its lists in the background.** **Save** returns at once and a progress bar
  shows the download of the DNS and IP lists, the country lists and the firewall tables, with a
  message if a step stalls. Before, the page waited for the downloads and could look hung.
- **No settings lost during a ThreatShield apply.** A long apply used to write back an old copy of the
  configuration, which could undo a setting saved in the meantime, for example the mDNS Bridge. It
  now reads the current configuration first, and the downloads no longer hold anything while they run.
- **CrowdSec starts after a reboot,** and stops when you disable it. It had to be saved again after
  every reboot.
- **Open-VM-Tools** no longer lists the VMware Kernel Modules service. Those modules are not part of
  the build for this FreeBSD, so the service always showed as stopped and logged a notice on every
  status refresh.
- **Correct Configure links.** The **Configure** link in the package catalog opened an error or an
  empty page for Avahi, lldpd, net-snmp, syslog-ng and UDP Broadcast Relay. Open-VM-Tools has no
  settings page and no longer shows the link.

### Images

- **Cloud images start the right guest tool.** `FreeSense-cloud-init` started the QEMU guest agent on
  every host and the VMware tools only after a probe. It now starts the tool that matches the
  hypervisor.
- **The domain of a NoCloud `local-hostname` is kept.** A `local-hostname` such as
  `edge-1.example.test` used to set the host name `edge-1` with the image's default domain. An
  explicit cloud-config `fqdn` or `hostname` still wins.

## What to check after updating

- **Version**: **Diagnostics → Command Prompt**, or a shell, `cat /etc/version` shows
  `1.1.12-RELEASE`.
- **Top bar**: the menu is on a second row and **System → General Setup** has the page width options.
- **Optional Packages**: update the packages the Package Manager offers (Telegraf, ThreatShield,
  CrowdSec, Open-VM-Tools and the catalog).

## Upgrade notes

- **From 1.1.0, 1.1.5, 1.1.9, 1.1.10 or 1.1.11:** a normal Stable update. See
  [Updates and release channels](/guides/updates-and-channels/).
- **From 1.1.1 to 1.1.4:** run the
  [console command](/releases/previous-1.1/#before-you-update-from-111-to-114-in-119) first.
- **From 1.0.x:** the upgrade to the 1.1 line is one-way. Read
  [Upgrading from 1.0](/guides/upgrading-from-1.0/) first.
- **Tested path:** a 1.1.11 amd64 system upgraded to the 1.1.12 release candidate with the FreeSense
  upgrader: it boots, reports 1.1.12 and PHP 8.5.12, the WebUI answers and the fixes above were
  checked on it, including after a reboot. Optional Packages were installed from the candidate
  repository; arm64 was built but not installed in that test.
