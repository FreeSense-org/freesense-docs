<p class="docs-edition-note"><strong>Development 1.2</strong> documentation. This line is experimental and unsupported. For production firewalls use the <a href="/">Stable 1.1 documentation</a>.</p>

<Aside type="danger" title="Experimental, no support">
Development builds are produced nightly from current sources. A build that passed its signature,
integrity, and boot checks is still experimental software and can contain defects that need a
reinstall to recover from. Moving a system from Stable to Development is one-way: the updater never
offers Stable again on a Development system. Keep a configuration backup and recovery media.
</Aside>

## One edition, fully open

FreeSense has a single edition. Development, Stable, and every optional package are built from
public, Apache-2.0 licensed sources. Report bugs found on Development builds as GitHub issues, and
report security problems privately through GitHub private vulnerability reporting.
