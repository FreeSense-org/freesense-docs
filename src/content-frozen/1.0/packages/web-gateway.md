---
title: Secure Web Gateway availability
description: Secure Web Gateway is not part of the FreeSense 1.0.5 Stable documentation set.
channels: [stable]
---

Secure Web Gateway is documented for the rolling **1.1 Development** line. It is not a supported
feature of the sealed FreeSense 1.0.5 Stable release.

Do not install or copy Web Gateway configuration from a development appliance into a 1.0.5 system.
For supported Stable web-service designs, use the services available in the 1.0.5 catalog and retain
the normal Stable update path.

Secure Web Gateway is part of FreeSense 1.1 Stable. See the
[current Secure Web Gateway guide](https://docs.freesense.org/packages/web-gateway/).
